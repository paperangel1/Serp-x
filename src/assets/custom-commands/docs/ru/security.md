# Безопасность и права

Каждый узел заранее объявляет **права** (capabilities): например `audio.control`, `window.manage`, `file.write`, `net.http`, `exec.script`, `ssh.server`, `net.gemini`, `servers.run`, `trigger.clipboard`, `trigger.notifications`, `vpn.control`, `window.close`, `screen.capture`. Права команды — объединение прав её узлов.

- Автоматизация не стартует, пока вы не подтвердили её права: «Эта команда сможет: …». Если узлы изменились и права выросли, подтверждение нужно снова.
- Импортированные и скопированные из галереи команды **выключены**, права не подтверждены, триггеры не работают. Ничего не исполняется при открытии файла.
- Скрипт, HTTP, SSH и запись файлов считаются чувствительными: они помечаются в списке прав. Скрипт запускается отдельным процессом с таймаутом и урезанным окружением; опасное действие просит подтверждения при каждом запуске, даже в автоматизации.
- Права с явным текстом в окне подтверждения: чтение буфера обмена и уведомлений (включая то, что содержимое нигде не сохраняется), отправка выбранного текста в Gemini (сервис Google), сеть (`net.http`), команды на серверах, управление VPN (включение и выключение без вопросов; Happ команды не трогают), закрытие окон, снимки экрана. Команды сервера с вводом имени (перезагрузка) из автоматизации не запускаются без отдельного права `servers.run.typed`.
- Файлы трогаются только внутри явно разрешённых папок; удаление — только в корзину.
- Секреты в файлах команд не хранятся (используйте `secret:имя`), в журнале маскируются.
- Защита от петель: ограничение запусков в минуту и предел времени запуска (`policy`).
