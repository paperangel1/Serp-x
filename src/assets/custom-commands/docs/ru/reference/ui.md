## Интерфейс

### Показать результат (`ui.show_result@1`)

Показывает значение в окне оболочки. Если оболочка не отвечает за 3 секунды, значение показывается обычным уведомлением.

- Вид: ожидание (может ждать)
- Права: нет
- Меняет состояние: нет
- Откат: нет
- Опасность: нет

| Пин | Направление | Тип | Подпись | По умолчанию |
|---|---|---|---|---|
| `exec_in` | вход | порядок выполнения |  |  |
| `title` | вход | текст | Заголовок |  |
| `value` | вход | любое значение | Значение |  |
| `exec_out` | выход | порядок выполнения | Готово |  |

**Пример:** Вывод команды «date» → показать результат.
