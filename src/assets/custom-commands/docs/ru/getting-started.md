# С чего начать

«Команды» — это визуальное программирование: вы соединяете узлы проводами, а оболочка выполняет получившийся граф. Никакого кода писать не нужно.

- **Узел** — один шаг: событие, действие, проверка, значение.
- **Провод** — связь между двумя кружками (пинами) узлов.
- **Команда** — граф с хотя бы одним событием. Хранится в файле `~/.config/serpantinum/commands/<имя>.cmd.json`.

Самая короткая команда: узел «Вручную» → узел «Уведомление». Соедините белый ромбик «Выполнить» первого узла с входом второго и нажмите «Запустить».

Обучение в окне «Команды» (кнопка «Обучение») проведёт по этому пути шаг за шагом. Готовые примеры лежат в «Галерее примеров».
