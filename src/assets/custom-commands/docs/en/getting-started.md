# Getting started

Commands is visual programming: you connect nodes with wires and the shell runs the resulting graph. No code needed.

- A **node** is one step: an event, an action, a check, a value.
- A **wire** connects two pins (circles) of nodes.
- A **command** is a graph with at least one event, stored in `~/.config/serpantinum/commands/<name>.cmd.json`.

The shortest command: a «Manual» node → a «Notification» node. Connect the white «Run» diamond of the first node to the input of the second and press «Run».

The tutorial in the Commands window (the «Tutorial» button) walks you through this step by step. Ready-made examples are in the «Example gallery».
