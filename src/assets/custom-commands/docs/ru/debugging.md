# Отладка и репетиция

- **Проверка.** Редактор постоянно проверяет граф: ошибки (красные) мешают запуску, предупреждения (жёлтые) — нет. Каждое сообщение говорит, что не так и как исправить.
- **Трасса.** После запуска откройте «Трассу»: по шагам видно, какой узел работал, какие значения вошли и вышли и сколько это заняло. `serpantinum-x cmd trace <имя>` показывает то же в терминале.
- **Значения при наведении.** Наведите курсор на пин: покажется значение из последнего запуска.
- **По шагам и точки останова.** Остановитесь на узле, посмотрите значения, шагните дальше или продолжите.
- **Репетиция.** Запуск «понарошку»: действия только описываются и ничего не меняют, время ускорено, на вопросы можно отвечать заранее (`--answer`), события для «Ждать событие» подставляются (`--sim-event`). Безопасно проверять новые команды: `serpantinum-x run "Имя" --rehearse --steps`.
- Журнал запусков: `serpantinum-x cmd log`.
