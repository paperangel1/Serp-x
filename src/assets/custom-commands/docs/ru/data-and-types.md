# Данные и типы

Цветные кружки — это данные. Данные текут по цветным проводам: от выхода одного узла к входу другого.

Провод соединяет только пины одного типа. Типы: `exec` (порядок), да/нет, число (`int`), дробное число (`float`), текст, время, длительность, цвет, путь, ссылка, устройство, данные (`json`), любое значение (`any`) и списки `list<тип>`.

- Неявно разрешены только два превращения: число → дробное и любой тип → «любое значение».
- Всё остальное делается явным узлом-преобразователем («В текст», «В число»). Если типы не совпали, редактор предлагает вставить его одним нажатием.
- «Чистые» узлы данных (математика, текст, сравнение) не имеют порядка выполнения: они считаются тогда, когда значение понадобилось.
- Вход, который не подключён, берёт значение из поля узла (литерал). Обязательный пустой вход — ошибка.
- Значения в журнале: секретные скрываются, длинные тексты и буфер обмена записываются только длиной.
