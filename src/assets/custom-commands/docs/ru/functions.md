# Функции (свои узлы)

Выделите несколько узлов и нажмите «Свернуть в узел»: редактор сам найдёт входы и выходы по проводам, которые пересекают выделение, и создаст функцию. Она появится в палитре как обычный узел и в «Библиотеке функций».

- Внутри функции есть узлы «Вход функции» и «Выход функции»: через них данные входят и выходят.
- Функцию можно открыть, изменить и сохранить: изменение коснётся всех мест, где она использована.
- Функция не может вызывать сама себя, даже через другие, а вложенность ограничена восемью уровнями.
- Права функции — объединение прав её узлов; они показываются в справке узла.
- Функции можно экспортировать и импортировать; чужая функция при импорте не получает подтверждённых прав.
