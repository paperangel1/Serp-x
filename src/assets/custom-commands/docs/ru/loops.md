# Циклы

Узел «Для каждого» берёт список и для каждого элемента проходит ветку «Тело». Выходы «Элемент» и «Номер» — данные текущего шага. Когда список кончился, идёт ветка «Завершено».

- «Прервать цикл» останавливает цикл досрочно; вне цикла он ошибка.
- Список можно взять из события, из узла `range` или разбить текст узлом «Разделить».
- Цикл без пауз по большому списку редактор отметит предупреждением: добавьте «Задержку» или ограничьте список.
- Повторять по времени проще событием «Интервал», чем бесконечным циклом.
