### Вручную (`event.manual@1`)

Запускает команду вручную: из палитры команд, по горячей клавише или командой serpantinum-x run. Если в команде есть любое другое событие, она становится автоматизацией.

- Вид: событие (запускает команду)
- Права: нет
- Меняет состояние: нет
- Откат: нет
- Опасность: нет

| Пин | Направление | Тип | Подпись | По умолчанию |
|---|---|---|---|---|
| `exec` | выход | порядок выполнения | Запуск |  |
| `arg` | выход | текст | Аргумент |  |

**Пример:** Вручную → Уведомление «Привет».
