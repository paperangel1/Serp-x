## Логика

### Спросить меня (`logic.ask@1`)

Показывает в оболочке вопрос: выбор из списка, ввод текста, ввод числа или «да/нет». Выходы «Отмена» и «Время вышло» срабатывают, если ответа нет. Если оболочка не подключена, идёт «Время вышло».

- Вид: ожидание (может ждать)
- Права: нет
- Меняет состояние: нет
- Откат: нет
- Опасность: нет

| Пин | Направление | Тип | Подпись | По умолчанию |
|---|---|---|---|---|
| `exec_in` | вход | порядок выполнения |  |  |
| `mode` | вход | текст | Вид вопроса | choice |
| `title` | вход | текст | Вопрос | Вопрос |
| `options` | вход | список (текст) | Варианты | [] |
| `default` | вход | текст | Значение по умолчанию |  |
| `timeout` | вход | дробное число | Ждать ответ (секунд) | 120 |
| `exec_out` | выход | порядок выполнения | Ответ получен |  |
| `cancelled` | выход | порядок выполнения | Отмена |  |
| `timed_out` | выход | порядок выполнения | Время вышло |  |
| `text` | выход | текст | Ответ (текст) |  |
| `number` | выход | дробное число | Ответ (число) |  |
| `index` | выход | число | Номер варианта | -1 |
| `yes` | выход | да/нет | Ответ «да» |  |

**Пример:** Спросить «Что включить?» с вариантами → действие по ответу.

- Вид: действие (идёт по проводу порядка выполнения)
- Права: нет
- Меняет состояние: нет
- Откат: нет
- Опасность: нет

| Пин | Направление | Тип | Подпись | По умолчанию |
|---|---|---|---|---|
| `exec_in` | вход | порядок выполнения |  |  |

**Пример:** Если нашли нужный файл → прервать цикл.

### Ждать событие (`logic.wait_event@1`)

Приостанавливает команду, пока не придёт подходящее событие (окно, рабочий стол, монитор, блокировка сеанса). Если за отведённое время события нет, идёт выход «Время вышло». Команду можно отменить во время ожидания.

- Вид: ожидание (может ждать)
- Права: `trigger.windows`, `trigger.session`
- Меняет состояние: нет
- Откат: нет
- Опасность: нет

| Пин | Направление | Тип | Подпись | По умолчанию |
|---|---|---|---|---|
| `exec_in` | вход | порядок выполнения |  |  |
| `event` | вход | текст | Событие | window.open |
| `match` | вход | текст | Фильтр |  |
| `timeout` | вход | дробное число | Ждать (секунд) | 60 |
| `exec_out` | выход | порядок выполнения | Событие пришло |  |
| `timed_out` | выход | порядок выполнения | Время вышло |  |
| `detail` | выход | текст | Данные события |  |

**Пример:** Ждать открытия окна браузера до 60 секунд → уведомление.
