# Переменные

Переменная хранит значение между шагами одного запуска. Объявите её в панели «Переменные» (имя и тип), потом пользуйтесь узлами:

- «Записать переменную» — кладёт значение;
- «Прочитать переменную» — чистый узел, отдаёт значение (тип берётся из объявления);
- «Увеличить» — прибавляет число (счётчики).

Переменные живут один запуск и не сохраняются между запусками. Тип переменной проверяется так же строго, как пины: в числовую переменную нельзя положить текст без преобразования. Имя, которого нет в объявлении, редактор подсветит ошибкой.
