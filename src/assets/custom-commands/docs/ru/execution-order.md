# Порядок выполнения

Порядок задаёт **белый провод** между ромбиками «Выполнить» и «Готово». Узел начинает работу, когда до него дошёл белый провод, и передаёт управление дальше только после того, как закончил.

- От события идёт одна цепочка: A → B → C. Два провода из одного выхода порядка нельзя: нужен узел «Если» или «Для каждого».
- Узел без белого провода не выполнится никогда. Редактор покажет предупреждение «недостижим».
- Ждущие узлы («Задержка», «Спросить меня», «Ждать событие») останавливают цепочку, пока не получат ответ или не истечёт время. Запуск можно отменить.
- Ошибка узла останавливает запуск, если у узла не выбрано «продолжить при ошибке».
- Замкнуть порядок в кольцо нельзя: для повторов есть цикл «Для каждого».
