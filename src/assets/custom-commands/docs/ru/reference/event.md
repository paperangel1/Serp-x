### Скопирован цвет (`event.clipboard.color@1`)

Срабатывает, когда в буфер скопирован цвет: «#rgb», «#rrggbb», «rgb(12, 34, 56)» или «hsl(200, 50%, 40%)» (весь буфер — только цвет). Отдаёт цвет в виде HEX и RGB. Это ТО ЖЕ отдельное право «слежение за буфером обмена», что и у «Скопирована ссылка»: оболочка читает буфер, пока команда включена. Содержимое получает только эта команда и нигде не сохраняется; в журнал попадает лишь вид и длина. Копирование самой командой («Положить в буфер») не считается.

- Вид: событие (запускает команду)
- Права: `trigger.clipboard`
- Меняет состояние: нет
- Откат: нет
- Опасность: нет

| Пин | Направление | Тип | Подпись | По умолчанию |
|---|---|---|---|---|
| `exec` | выход | порядок выполнения | Запуск |  |
| `hex` | выход | текст | HEX |  |
| `rgb` | выход | текст | RGB |  |

**Пример:** Скопировали «#3b82f6» → показать HEX и RGB.
